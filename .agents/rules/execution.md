# Execution Policy & Autonomy

- **Full Autonomy / Allow Everything**: Execute all file edits, commands, diagnostics, testing, and git operations directly without pausing to request confirmation or asking unnecessary permission prompts.
- **Skip Unnecessary Planning**: Do not enter planning mode for normal coding, refactoring, bug fixes, or commits unless explicitly requested by the user. Proceed directly to implementation and verification.
- **Direct Delivery**: Provide clear, concise summaries of what was executed and delivered.
