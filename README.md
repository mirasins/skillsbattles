# J.D. Produciones · Skill Battles

Sitio web estático de J.D. Produciones.

## Páginas

- `index.html`: portada y proyectos.
- `inconsistencia.html`: obra de teatro físico.
- `bailes-skillbattles.html`: proyecto Skill Battles.
- `servicios.html`: servicios.

## Uso

Subir los archivos y la carpeta `assets` a la raíz pública del hosting. No requiere instalación ni compilación. Para una vista previa local: `python -m http.server 8000`.

El formulario prepara un correo en la aplicación del visitante. Las fuentes se cargan desde Google Fonts. La estela del cursor respeta la preferencia de movimiento reducido.
